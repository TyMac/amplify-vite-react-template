## Updates applied

Package updates were limited to dependency lines needed to pick up available security fixes while staying within the same major versions:

- `@aws-amplify/ui-react`: `~6.13.2` -> `~6.15.4`
  - pulls fixed UI/lodash dependency chain
- `aws-amplify`: `~6.15.10` -> `~6.17.0`
  - needed to align with `@aws-amplify/ui-react@6.15.4` and keep one deduped `@aws-amplify/core@6.16.3`
  - avoids the known Barista `generateClient()` / duplicate Amplify singleton failure mode
- `@aws-amplify/backend`: `~1.19.0` -> `~1.22.0`
  - latest same-major backend construct package available at audit time
- `@aws-amplify/backend-cli`: `~1.8.1` -> `~1.8.2`
  - minimum wanted patch release
- `vite`: `~7.3.1` -> `~7.3.3`
  - minimum patch line fixing the direct Vite dev-server advisories

`package-lock.json` was regenerated with `npm install`.
